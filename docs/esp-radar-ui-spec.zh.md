# 胶囊雷达端用户 UI 规格

更新时间：2026-07-20

本文定义 ESP32-S3-Touch-AMOLED-1.75C 圆屏雷达端的用户界面。它补齐 App 信息架构之外的现场终端体验，作为后续固件 UI 调整和真机验收依据。

## 设计目标

雷达端是现场主终端，不是配置后台。用户拿起设备后应只关心三件事：

1. 当前雷达是否可用。
2. 同房间其他成员在哪里、距离多远、谁在说话。
3. 按住 BOOT 能不能说话，松手后是否结束。

雷达端不展示账号、房间管理、Wi-Fi 密码、device token、协议版本、BLE 特征名等开发信息。这些信息只进入 App 诊断包或串口诊断。

## 视觉原则

- 主视觉采用原创复古科技雷达感：黑底、绿色网格、橙色圆形成员点、少量琥珀色告警。
- 圆屏内不使用大矩形信息卡，不遮挡雷达中心和圆形成员点。
- 用户可见文字必须短，优先使用状态词：`CONNECTED`、`SIGNAL LOST`、`NO SIGNAL`、`LOW BATTERY`。
- 调试信息默认不显示。Debug HUD 只用于开发构建或串口命令触发。
- 圆形成员点优先级高于距离标签；重叠时宁可隐藏/避让标签，也不能盖住成员点。
- 界面不包含隐藏角色、虚拟宠物、彩蛋入口、道具收集或召唤玩法。

## 屏幕状态模型

雷达端 UI 按以下状态优先级显示，高优先级覆盖低优先级：

| 优先级 | 状态 | 触发条件 | 用户看到 |
| --- | --- | --- | --- |
| 1 | 启动 | 上电到主界面前 | 启动画面和启动音 |
| 2 | 系统菜单 | 用户按电源键进入设备级菜单 | 熄屏、待机、关机、亮度、音量、状态 |
| 3 | 关机确认 | 用户选择关机 | `HOLD TO OFF` 弧形确认 |
| 4 | 网络异常 | Wi-Fi 未连接或 Relay 未连接 | 沿屏幕边缘移动的 `SIGNAL LOST` |
| 5 | 低电量 | 电池存在且低于阈值 | 圆心上方 `LOW BATTERY` |
| 6 | 无成员信号 | Relay 已连接，但当前房间没有其他成员 GPS | 圆心上方 `NO SIGNAL` |
| 7 | 抢麦/语音 | 本机按住说话、远端说话、抢麦失败 | 边缘波纹、说话者轻标识、busy 反馈 |
| 8 | 主雷达 | 有可显示成员定位 | 网格、圆形成员点、距离、运动/说话标识 |
| 9 | 临时反馈 | 音量、亮度、短按切换、触摸 | 700ms 以内的轻量反馈 |

同一时刻如果出现多个异常，显示顺序为：网络异常 > 低电量 > 无成员信号。这样用户不会把网络问题误解为房间没人。

## 启动 UI

目标：让用户确认设备已开机，但不打断后续定位。

- 启动时显示原创纯雷达启动画面：深绿雷达圆环、扫描线、中心定位点和独立品牌文字；不使用胶囊形道具、角色、宠物、彩蛋或第三方标志。
- 启动音采用固件内按频率和时长实时合成的原创六音短提示，不包含采样音乐、录音或第三方音频资产；只播放一次，音量固定为可听但不炸麦，不受运行时音量档位影响。
- 启动音播放期间，如果用户按住 BOOT 进入 PTT，启动音必须立即停止。
- 进入主雷达后不再显示启动说明文字。

验收：

- 上电后 3 秒内进入主雷达或明确异常状态。
- 启动音无破音、无尾音爆裂。
- 启动音不会和 PTT 录音重叠。

## 主雷达 UI

主雷达是默认界面。

固定元素：

- 黑色圆屏背景。
- 绿色雷达网格，直径占满 8 格。
- 中心本机红色三角形或本机标识。
- 同房间远端成员以橙色圆点显示；成员点不含星纹、角色轮廓、宠物特征或第三方标志。
- IMU 已取得可信零偏且用户完成北向零点校准后，绿色网格与成员按雷达本体相对转角整体旋转；中心本机标识保持固定。可信零偏可以来自本次严格静止验证，也可以来自温度匹配的已保存零偏。

成员显示规则：

- 最多显示 6 个远端成员，加上本机为 7 组房间上限。
- 只显示有有效 GPS 的远端成员。
- 超出当前缩放范围的成员不显示。
- 成员先在未旋转的世界网格中按既有半格步长吸附，并使用换格滞回防止 GPS 在边界附近来回跳动；随后与网格使用同一旋转矩阵。
- BOOT 短按只切换关注成员并把缩放比例调整到该成员可见；不得修改北向校准偏移，其他在范围内的成员仍然显示。
- 关注成员按距离从近到远机械循环；距离变化时不应突然跳到另一个成员，除非用户再次短按。
- 关注成员的四角锁定框在下一次切换前保持可见；切换后的前 900ms 可增强闪烁，之后保留稳定的橙色暗框。

北向零点校准：

- 启动动画结束后，未校准的主雷达只在本次开机显示一次 `POINT ZERO TO N / HOLD SCREEN / TRUE NORTH`。用户将雷达尽量平放，把机身零点/屏幕 12 点方向对准真北 N，再静止长按屏幕 1.2 秒。BOOT 短按或屏幕短触只关闭这次开机提示；关闭后不再弹出教学提示，但主雷达上的静止长按校准始终可用，包括已经校准后再次长按重校准。
- 校准只依赖雷达本体 QMI8658：必须先取得可信零偏、IMU 样本不超过 250ms 且长按结束时角速度不高于 3°/s；不依赖 GPS、房间成员或手机朝向。已保存零偏只有在存储结构有效、当前温度与保存温度均可用且温差不超过 6°C 时才直接用于本次会话；否则仍执行严格静止验证。
- 设长按成功时 QMI 逆时针相对 yaw 为 `G0`，会话偏移 `C = wrap360(-G0)`；任一 GPS 真北方位 `B` 的屏幕角为 `wrap360(B+G+C)`，因此成功瞬间 N 位于屏幕 12 点。
- 成功后短暂显示 `NORTH ALIGNED`。未成功前旋转固定为 0°，不得把任意启动 yaw 表现成已获得北向参考；主雷达不额外绘制外圈 `N` 刻度线。
- 首次使用、保存零偏不可用或温差过大时显示 `KEEP RADAR STILL`；在线 IMU 正在学习零偏时使用 `HOLD STILL`，只有 IMU 离线或样本过期才显示 `IMU WAIT`。物理触摸达到 1.2 秒后必须被识别为一次长按并消费，不能因 IMU 尚未就绪而重置计时或在松手时误判为短触；若手指继续按住，静止验证通过后立即完成校准。中途松手则保持未校准和启动提示，不得延迟自动校准。首次严格验证通过的零偏立即保存，后续温度匹配的开机和待机唤醒不再重复等待。
- 偏移只在本次 IMU 会话内有效，不写入 NVS。切成员、切房和网络重连不得清除；熄屏且 IMU 持续运行时保留；待机、重启、IMU 重置或无法积分的采样间断时清除。只有真实开机重新显示教学提示，待机唤醒和运行中的 IMU 断档不弹出；用户可随时静止长按屏幕 1.2 秒重新校准。
- 用户是否真正对准真北无法由陀螺仪自动验证，因此成功文案只表示“北向零点已按用户操作设定”，不能声称自动识别了真北；若按磁北对准，会保留当地磁偏角误差。
- 圆形成员点继续遵守世界网格吸附；锁定成员只显示原有四角锁定框，不额外绘制真实方位刻度线。

距离显示：

- 距离显示在对应圆形成员点附近。
- `< 995m` 显示 `Xm`。
- `995m - 9.95km` 显示 `X.Xkm`。
- `>= 9.95km` 显示整数 `Xkm`。
- 距离标签不得遮挡圆形成员点；发生重叠时优先保留成员点。

定位新鲜度：

- 成员首次出现时可给一次非遮挡式出现反馈；后续定位更新不得让圆形成员点熄灭或消失。
- 连续定位采用精度相关平滑，禁止把原始 GPS 抖动直接表现为跳点。
- 过期定位不作为实时圆形成员点显示；后续可增加淡化历史点，但首版默认隐藏。

## 无信号和网络异常

`SIGNAL LOST`：

- 表示雷达自身网络链路异常。
- 触发条件：Wi-Fi 未连接，或 Wi-Fi 已连但 Relay 未连接。
- 显示方式：文字贴近圆屏边缘，沿圆周顺时针移动，直到网络恢复。
- 网络恢复后，在同一位置显示绿色 `CONNECTED`，闪烁两次后消失。

`NO SIGNAL`：

- 表示雷达已连上房间，但房间内没有其他成员 GPS 信号。
- 显示位置：圆心和顶部之间，保持和现有 `SIGNAL LOST` 风格一致。
- 闪烁显示。

`LOW BATTERY`：

- 表示本机雷达电量低。
- 显示位置和字体风格与 `NO SIGNAL` 一致。
- 不播放告警音，避免和语音使用冲突。

## 语音 UI

雷达端是语音主体，App 只管理状态和房间。

PTT 操作：

- BOOT 长按：请求说话。
- BOOT 松手：释放说话。
- 如果房间已有其他成员说话，本机不得开始上传语音，显示轻量 busy 反馈。

本机说话反馈：

- 按下 BOOT 后，屏幕边缘在按键对应位置出现被按下推起的“拱”。
- 按住期间，拱随语音峰值轻微增强。
- 松手后，波纹从按键位置沿圆周两个方向扩散并衰减。
- PTT 期间关闭启动音、告警音、按键音和远端播放，避免影响麦克风。

远端说话反馈：

- 当前说话成员对应圆形成员点旁显示轻量说话标识。
- 只显示当前抢麦者，不做多人同时发声 UI，因为房间规则只允许一个成员说话。
- 远端语音播放时，不显示大弹窗，不遮挡雷达。

抢麦失败：

- 如果收到 `voice_busy`，本机 PTT 立即取消。
- 屏幕显示短暂边缘反馈，不显示开发错误码。
- 可选声音反馈必须低优先级，不能打断正在播放的远端语音。

## 系统菜单 UI

系统菜单是雷达端的设备级入口，用来管理电源、屏幕、音量、亮度和状态查看。它覆盖旧的 `LUX/VOL` 设置页；亮度和音量仍保留，但作为系统菜单里的两个项目。

入口：

- AXP 电源键短按：打开或关闭系统菜单。
- AXP 电源键长按：从任意非语音状态进入关机确认，不直接关机。
- 屏幕熄灭或待机时，电源键短按只负责唤醒，不直接打开菜单。
- BOOT 不作为系统菜单入口，继续保留给主雷达短按切换和长按 PTT。
- 本机正在 PTT 时禁止打开系统菜单；先松开 BOOT 再允许进入。

主菜单布局：

- 使用单页聚焦 HMI，不同时展示七个竞争按钮，也不使用矩形卡片。
- 七页固定顺序为 `SLP -> STB -> OFF -> INF -> VOL -> LUX -> DIR`，底部 7 个短刻度只表示当前位置。
- 当前页只显示一个三字符大号缩写和一个主要可视化控件，左右边缘保留大号切页箭头。
- 左右滑动屏幕或点按左右箭头切换页面；切换只改变当前页，不立即执行功能。
- 点按下半部中央圆形操作区确认当前功能；`LUX`、`VOL` 确认后停留在当前页，并逐档调整。
- `VOL` 使用 5 根等高柱显示音量，`LUX` 使用 5 根递增柱显示亮度；中央圆圈显示当前档位数字。
- `SLP`、`STB`、`OFF`、`INF` 分别使用月牙、暂停、电源、四状态灯作为主可视化，中央圆圈使用确认符号；`DIR` 使用朝上/朝下箭头和 `12/6` 数值。
- `OFF` 的缩写、图标和确认反馈使用琥珀色；其他页面使用白色大字和绿色磷光状态。
- 按下左右箭头时箭头向内收缩，松手后回弹；按下中央操作区时按钮收缩下沉，松手后外扩回弹，完整反馈在 220ms 内结束。
- 切换功能页时，大号缩写和主可视化沿切换方向滑入，180ms 内稳定；`VOL`、`LUX` 调档成功后已启用柱条短暂变白。
- 系统菜单反馈只使用控件动画，不显示触点位置，也不播放按键音。
- 再次短按电源键退出到主雷达。
- 菜单 8 秒无操作自动回到主雷达；如果用户从熄屏唤醒，只回到主雷达。

菜单项目：

| 项目 | 文案 | 行为 |
| --- | --- | --- |
| 熄屏 | `SLP` | 关闭屏幕显示，设备继续在线，定位、房间、语音链路保持工作 |
| 待机 | `STB` | 关闭屏幕和连续雷达刷新，降低心跳/绘制频率，保留最小联网状态 |
| 关机 | `OFF` | 进入二次确认；确认后保存状态并执行软关机流程 |
| 亮度 | `LUX` | 调整屏幕亮度，5 档 |
| 音量 | `VOL` | 调整运行时音量，0 档完全静音 |
| 状态 | `INF` | 查看用户能理解的雷达状态 |
| 屏幕方向 | `DIR` | 在接口朝 6 点与接口朝 12 点两种握持方向间切换；整个 UI 旋转 180°，触摸坐标同步反转并写入 NVS，重启后保留 |

### 屏幕方向

- 默认方向为接口/USB-C 位于 6 点，`DIR` 中显示 `6` 和向下箭头。
- 在 `DIR` 页点按中央操作区后切换为接口位于 12 点，显示 `12` 和向上箭头；再次点按恢复 6 点。
- 翻转必须作用于完整圆屏 UI，包括主雷达、系统菜单、启动画面、异常文字和临时反馈，不能只旋转成员点或文字层。
- 物理触摸坐标必须随显示做 180° 映射，翻转后菜单左右切页、中央确认和主雷达长按校准仍落在用户看到的位置。
- 当前方向写入 `dragonRadar` Preferences 的 `screenDir`，仅接受 `6` 或 `12`；缺失或非法值回退为 6 点。
- 屏幕方向只改变握持和触控坐标，不改变 GPS 真北方位、QMI8658 yaw 符号、北向校准公式、BOOT PTT 或 AXP 电源键含义。

`INFO` 只显示：

- 网络：`WIFI OK` / `WIFI LOST`
- 房间：`ROOM OK` / `ROOM LOST`
- 语音：`VOICE OK` / `VOICE BUSY` / `VOICE LOST`
- 电量：百分比或 `BAT UNKNOWN`
- 版本：用户版本号，例如 `R1.0`

`INFO` 不显示：

- Wi-Fi SSID
- Relay URL
- 房间码
- device token
- BLE 特征状态
- 协议版本

### 熄屏

`SLEEP` 用于临时不看屏幕，但雷达仍作为对讲终端工作。

进入后：

- AMOLED 显示关闭或亮度降到 0。
- 主雷达绘制暂停。
- Wi-Fi、Relay、房间状态、GPS 接收、语音抢麦保持。
- `SIGNAL LOST`、`NO SIGNAL`、`LOW BATTERY` 不在屏幕上显示；网络恢复后也不显示 `CONNECTED`。
- 远端语音仍按音量设置播放。
- BOOT 长按仍可直接 PTT；按下后屏幕以低亮度临时亮起并显示 PTT 边缘波纹。

唤醒：

- 电源键短按：唤醒到主雷达。
- 触摸：只唤醒到主雷达，不触发菜单。
- BOOT 短按：只唤醒，不切换成员。
- BOOT 长按：唤醒并进入 PTT。

### 待机

`STBY` 用于长时间携带，目标是降低耗电和减少误触。

进入后：

- 屏幕关闭。
- 雷达动画、网格刷新、圆形成员点刷新暂停。
- Relay 保持最低在线状态，继续上报 `power_state=standby`。
- 不播放 `NO SIGNAL` 提示音。
- 远端语音不自动播放，只保留抢麦和房间状态。
- BOOT 长按不直接 PTT，必须先唤醒再说话，避免口袋误触。

唤醒：

- 电源键短按：唤醒到主雷达。
- 触摸长按 600ms：唤醒到主雷达。
- BOOT 短按：唤醒到主雷达。

### 关机

`OFF` 必须二次确认，避免用户误触导致设备离线。

确认 UI：

- 屏幕上沿显示 `HOLD TO OFF`。
- 用户长按电源键或按住 `OFF` 区域 1.5 秒，圆周进度条走满后确认。
- 松手、BOOT 短按、触摸菜单外区域都取消。
- 确认期间不播放提示音。

关机流程：

1. 停止 PTT 和非语音音效。
2. 保存亮度、音量、当前房间、关注成员等本地状态。
3. 向 Relay 上报 `power_state=shutdown_pending`。
4. 主动断开 Relay。
5. 执行已验证的 AXP2101 PMIC 关机流程。
6. 如果 PMIC 关机寄存器未在本项目真机验证通过，则降级为深度休眠，不在 UI 上承诺“完全断电”。

### 亮度和音量

`LUX`：

- 5 档亮度。
- 0 档不用于正常亮度，熄屏必须通过 `SLEEP` 进入，避免用户以为设备坏了。
- 调整时显示 700ms 以内的柱状反馈。

`VOL`：

- 6 档：`MUTE`、1、2、3、4、5。
- `MUTE` 为完全静音。
- 运行时音量只影响远端语音和 `NO SIGNAL` 告警音。
- 启动音使用独立固定音量，不受 `VOL` 影响。

## 电源状态上报

雷达端需要向 Relay 或 App 可读状态中上报设备级状态，避免 App 显示“可用”但设备实际已熄屏或待机。

建议字段：

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| `power_state` | `active` / `screen_off` / `standby` / `shutdown_pending` | 雷达当前电源状态 |
| `display_state` | `on` / `off` / `dim` | 屏幕状态 |
| `battery_percent` | `76` | 电量百分比，不可用时省略 |
| `battery_charging` | `true` / `false` | 是否充电 |
| `last_user_input_ms` | `12345678` | 最近一次用户输入时间 |

状态传输约束：

- BLE 优先发送 App 配置页需要的完整设备状态；若完整 105 超过 512 字节，则回退为只保留固件身份、OTA、绑定与所有者鉴权、Wi-Fi、服务器、定位、电量和最近事件的 compact 105。
- compact 105 省略 `relay`、`power_state` 和 `display_state`；语音 RMS、峰值、收发序号、`last_user_input_ms`、协议元数据和完整电源/屏幕遥测仍由 Relay 上报。
- BLE 特征值必须小于等于 512 字节；固件先执行 compact 回退，只有 compact 后仍超限才丢弃该次状态。最近事件最长保留 64 字节，超限改为 `status_event_truncated`。
- 2026-07-14 真机 OTA 诊断中，修复前完整 105 曾达到 523 字节并导致 App 收不到状态；修复后 compact 105 已在实体 iPhone 上完成 owner 鉴权与 OTA。当前字段上界的静态保守预算为 488 字节，Relay 继续保留完整遥测。

App 只展示用户语言：

- `active`：雷达在线。
- `screen_off`：雷达已熄屏。
- `standby`：雷达待机中。
- `shutdown_pending`：雷达正在关机。

## 按键与触摸

BOOT：

- 短按：若启动北向提示仍在，先关闭提示；随后只切换关注成员并缩放到该成员可见。不得触发、重新显示、覆盖或清除北向零点校准；无可切换成员时不再回退为缩放操作。
- 长按：PTT 说话。
- 松手：结束 PTT。
- 屏幕熄灭时短按只唤醒，不切换成员。
- 待机时短按只唤醒，不切换成员。

AXP 电源键：

- 主雷达短按：打开系统菜单。
- 系统菜单短按：关闭系统菜单，回到主雷达。
- 熄屏/待机短按：唤醒到主雷达。
- 任意非语音状态长按：进入关机确认。
- PTT 录音期间长按不关机，只在松开 BOOT 后允许处理关机确认。

其他可用按键或触摸：

- 点按：轻量水波/边框反馈。
- 系统菜单内左右滑动或点按左右箭头：切换当前功能页。
- 系统菜单中央操作区点按：执行当前功能或调整当前档位。
- 系统菜单其他区域点按：只显示触摸反馈，不执行功能。
- 触摸长按：只作为待机唤醒，不作为日常菜单入口。
- 不设置任何角色、宠物、彩蛋或收集玩法入口；BOOT 始终只承担成员切换、唤醒和 PTT 等雷达核心操作。

按键优先级：

1. BOOT 长按 PTT 最高优先级。
2. 正在 PTT 时，任何系统菜单、熄屏、待机、关机操作都延后或忽略。
3. 电源键长按只打开关机确认，不直接断电。
4. 电源键短按负责系统菜单和唤醒。
5. BOOT 短按只在主雷达活跃状态下切换成员。

## 验收标准

主雷达：

- 两组以上成员在线时，每组只显示一个圆形成员点。
- 手机移动后，雷达端距离在 2 到 10 秒内更新。
- 超出当前范围的成员不显示；短按关注后能缩放到该成员可见。
- 距离标签不遮挡圆形成员点。
- 关注框在成员保持锁定期间持续可见，而不是 900ms 后消失。
- 只有启动后显示一次北向零点教学提示；待机唤醒、IMU 断档以及提示被关闭后的重校准均不再次弹出。雷达平放并以 12 点对准真北，主界面静止长按屏幕 1.2 秒后显示 `NORTH ALIGNED`。
- 长按校准是主雷达常驻功能，当前已经校准时再次静止长按 1.2 秒也会覆盖旧偏移。IMU 未稳定、样本过期或雷达仍在转动时不接受，但达到 1.2 秒的失败长按必须显示等待/静止反馈且不能关闭启动提示；手指仍按住并随后满足门限时立即校准。屏幕短触、滑动、菜单/待机/关机确认中的长按均不校准。
- 校准后顺时针转动雷达时，绿色网格、所有成员和运动箭头使用同一角度整体反向转动；不显示外圈 `N` 或目标方位刻度线。
- 连续短按 BOOT 只关闭尚在显示的启动提示、循环成员和调整缩放，校准偏移保持不变；提示关闭后短按不得再次唤出；无成员时短按不再执行缩放或校准。
- 切成员、切房、GPS 更新和网络重连不得重算或清除北向偏移；熄屏保持，待机、重启和 IMU 积分断档清除。

异常：

- 断 Wi-Fi 或断 Relay 时显示 `SIGNAL LOST`。
- Relay 在线但无其他 GPS 时显示 `NO SIGNAL`。
- 低电量时显示 `LOW BATTERY`。
- 网络恢复显示绿色 `CONNECTED`，闪烁两次后消失。

语音：

- 长按 BOOT 开始说话，松手停止。
- 一人说话时，其他成员抢麦失败且不会上传语音。
- 远端说话时本机播放清楚，并显示说话成员。
- 本机 PTT 期间无启动音、告警音、按键音、远端播放进麦。

系统菜单：

- 电源键短按能进入系统菜单，再短按能退出。
- 左右滑动和左右箭头都能按固定顺序循环切换六页，切页本身不执行功能。
- 左右箭头和中央操作区按下后立即收缩，松手后在 220ms 内回弹，且不显示触点位置、不播放按键音。
- 只有中央圆形操作区能执行当前功能，其他空白区域点按不会误触发。
- 用户能在 10 秒内完成亮度调整。
- 用户能在 10 秒内完成音量调整。
- 0 档完全静音，其余档位有可感知差异。
- 用户能一键进入熄屏，且能用电源键短按唤醒。
- 用户能进入待机，且待机时不会因 BOOT 误触直接开始 PTT。
- 关机必须经过二次确认，松手或点菜单外能取消。
- 关机前会保存本地状态并向服务端上报 `shutdown_pending`。
